## Practice Question #1

**Which Azure service provides virtual machines that allow you to run Windows or Linux operating systems in the cloud?**

A. Azure Blob Storage  
B. Azure Virtual Machines  
C. Azure Functions  
D. Azure DNS  

### Answer

**B. Azure Virtual Machines**

Azure Virtual Machines (VMs) provide scalable computing resources in Microsoft Azure and allow users to run Windows or Linux virtual machines in the cloud.

## Practice Question #2

**Which Azure service is primarily used to store unstructured data such as images, videos, and documents?**

A. Azure Blob Storage  
B. Azure SQL Database  
C. Azure Virtual Network  
D. Azure DNS  

### Answer

**A. Azure Blob Storage**

Azure Blob Storage is designed for storing large amounts of unstructured data, including text, images, videos, and documents.
