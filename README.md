## Practice Question #1

**Which Azure service provides virtual machines that allow you to run Windows or Linux operating systems in the cloud?**

A. Azure Blob Storage  
B. Azure Virtual Machines  
C. Azure Functions  
D. Azure DNS  

### Answer

**B. Azure Virtual Machines**

Azure Virtual Machines (VMs) provide scalable computing resources in Microsoft Azure and allow users to run Windows or Linux virtual machines in the cloud.

## Practice Question #2

**Which Azure service is primarily used to store unstructured data such as images, videos, and documents?**

A. Azure Blob Storage  
B. Azure SQL Database  
C. Azure Virtual Network  
D. Azure DNS  

### Answer

**A. Azure Blob Storage**

Azure Blob Storage is designed for storing large amounts of unstructured data, including text, images, videos, and documents.

## More AZ-900 Practice Questions

### Practice Question #3

**Which Azure service provides serverless compute that runs code in response to events?**

A. Azure Virtual Machines  
B. Azure Functions  
C. Azure Storage  
D. Azure Virtual Network  

**Answer: B. Azure Functions**

Azure Functions is a serverless compute service that executes code in response to events without requiring you to manage the underlying servers.

---

### Practice Question #4

**Which Azure service is used to create a logically isolated network in Azure?**

A. Azure Virtual Network  
B. Azure Blob Storage  
C. Azure Monitor  
D. Azure DNS  

**Answer: A. Azure Virtual Network**

Azure Virtual Network (VNet) enables resources such as virtual machines to communicate securely within an isolated network.

---

### Practice Question #5

**Which Azure service helps monitor the performance and availability of Azure resources?**

A. Azure Monitor  
B. Azure DevOps  
C. Azure DNS  
D. Azure Files  

**Answer: A. Azure Monitor**

Azure Monitor collects and analyzes monitoring data from Azure resources and applications.

---

### Practice Question #6

**Which Azure service provides object storage for unstructured data?**

A. Azure SQL Database  
B. Azure Blob Storage  
C. Azure Virtual Network  
D. Azure Kubernetes Service  

**Answer: B. Azure Blob Storage**

Blob Storage is designed for large amounts of unstructured data such as images, videos, documents, and backups.

### Practice Question #7

**Which Azure service provides a managed relational database?**

A. Azure SQL Database  
B. Azure Blob Storage  
C. Azure Queue Storage  
D. Azure DNS  

**Answer: A. Azure SQL Database**

Azure SQL Database is a fully managed relational database service based on Microsoft SQL Server.

### Practice Question #8

**What is the primary purpose of Microsoft Entra ID?**

A. Store application files  
B. Manage identities and access  
C. Host virtual machines  
D. Monitor network traffic  

**Answer: B. Manage identities and access**

Microsoft Entra ID provides identity and access management capabilities for users, applications, and resources.

---

### Practice Question #9

**Which Azure service can distribute incoming network traffic across multiple servers?**

A. Azure Load Balancer  
B. Azure Blob Storage  
C. Azure Key Vault  
D. Azure Policy  

**Answer: A. Azure Load Balancer**

Azure Load Balancer distributes incoming network traffic across multiple backend resources to improve availability and scalability.

### Practice Question #10

A. Azure Monitor
